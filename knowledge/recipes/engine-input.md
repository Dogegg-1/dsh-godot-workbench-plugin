# 按键映射、UI 吞输入与重复点击

适用：点击没反应、打开菜单后角色仍行动、按一次购买两次。

方案 A：连续移动用动作状态查询，适合按住行为。方案 B：菜单、交互用离散事件或按钮信号，适合一次性动作。不要让同一购买同时由按钮信号和全局鼠标事件结算。

做法：在 InputMap 定义 move_left、interact 等语义动作；先记录事件进入哪一层，再检查 UI 是否消耗它。记录每次结算的调用来源和次数，排查重复连接、键盘重复与同帧双入口。

验收：真实点击 1 次只扣款 1 次；长按是否重复必须有明确设计；菜单打开时操作菜单不触发地图行为。鼠标、键盘与手柄分别核对焦点。

边界：直接调用购买函数只能验证数值逻辑，不能证明输入链路工作。具体回调顺序查当前版本官方文档。
