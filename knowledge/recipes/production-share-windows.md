# 让朋友解压就能试玩 Windows 包

## 适用

把 Windows 试玩版发给朋友，对方机器上没有 Godot 编辑器。

## 做法

1. 用 Windows 导出预设生成独立构建，选择试玩设备能运行的架构。导出的程序使用运行模板。若内容包 `.pck` 单独生成，保留它与 `.exe` 的相对位置和文件名，同时带上导出产生的必要依赖。 [Godot 4.7 Windows 导出](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_windows.html)
2. 从本次输出目录打包，附一小段说明：解压到普通目录、打开哪个程序、怎么操作、反馈时记录哪一步。记录构建编号。打包前核对目录清单，排除源码、真实玩家存档、测试日志和凭据。
3. 先自己从 ZIP 解压到另一个目录启动，再给朋友同一份 ZIP。收到反馈时用构建编号对齐版本，避免修的是另外一个包。

## 验证

在未装 Godot 编辑器的 Windows 上，解压、启动、完成一轮核心玩法、保存并重开。记录设备架构、构建编号、首个失败步骤。保存通过以重开后的进度为准。

## 边界

这是 Windows 试玩分发流程。其他系统、第三方依赖、签名和平台发布各有要求，按目标环境另测。压缩包生成、启动成功和真人试玩分别记录。
