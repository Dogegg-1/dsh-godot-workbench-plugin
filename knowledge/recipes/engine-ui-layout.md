# 窗口缩放与 UI 容器布局

适用：窗口缩放、长文本或本地化后按钮重叠、超出边界。

方案 A：少量固定 HUD 用锚点和边距，结构简单但复杂列表维护成本高。方案 B：设置菜单和商店用嵌套 Container，布局更稳，但必须按容器规则设置最小尺寸和扩展。推荐复杂 UI 选 B。

做法：先查父节点是否为 Container；若是，取消对子 Control 的逐帧 position/size 覆盖。把标题、价格、按钮拆为清晰层次，长文本允许换行，列表超过可视区再滚动。

验收起点：800×600、1280×720 与 390 像素宽窗口分别检查；这些是测试样本，不是通用目标分辨率。用“购买失败原因很长的文本”和 8 位价格检查挤压。

边界：官方来源确认容器布局机制；具体窗口尺寸、层次和验收步骤是本项目建议。锚点规则另查官方 Size and anchors。
