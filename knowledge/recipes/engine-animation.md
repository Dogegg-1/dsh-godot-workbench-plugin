# 动画覆盖参数与 AnimationPlayer 分工

适用：在编辑器调整颜色或位置，运行后又变回；动画切换闪一下。

方案 A：固定演出用 AnimationPlayer 时间线，方便逐帧调整但轨道路径需维护。方案 B：短促 UI 过渡用临时 Tween，组合灵活但要管理取消和重复创建。先确定哪个系统拥有同一属性。

做法：查每条动画对该属性的轨道；临时禁用动画验证覆盖来源。把“逻辑位置”和“表现偏移”分在不同节点，减少同时写入。重入同一效果时明确替换还是叠加。

参数试验：用 0.08、0.15、0.25 秒三个候选过渡比较响应；这些是可测试起点，不是统一规范。

验收：连续快速触发、动画中切场景、暂停后恢复、重新进入场景，检查是否残留偏移。API 细节通过本机参考工具核对。
